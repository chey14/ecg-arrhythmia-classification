
# ECG Arrhythmia Classification

An educational machine learning and deep learning project
for classifying heartbeat segments from ECG recordings.

## Project goals

- Explore ECG signals from the MIT-BIH Arrhythmia Database.
- Preprocess signals and extract heartbeat segments.
- Train a Random Forest baseline.
- Build a 1D Convolutional Neural Network using PyTorch.
- Compare models using appropriate evaluation metrics.
- Develop a Streamlit demonstration application.

## Technology stack

Python, NumPy, Pandas, SciPy, scikit-learn, WFDB,
PyTorch, Matplotlib and Streamlit.

## Project status

In progress. Results and implementation details will be
documented as the project develops.

## Important note

This is an educational research prototype, not a
medical diagnostic device.

## Setup

Create and activate a Python virtual environment,
then install the dependencies:

    python -m pip install -r requirements.txt
